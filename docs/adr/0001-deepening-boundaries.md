# ADR-0001: границы углубления модулей прогона (0.19.0)

Дата: 2026-10-04
Статус: принято

## Контекст

Архитектурный обзор (6 кандидатов) нашёл фрикцию в трёх шэйпах одного
концепта (снимок фида), дубле решения «активна ли рубрикация» и
глобалах LLM. Четыре кандидата закрыты кодом: `feed_snapshot`/
`feed_runtime` (единая форма фида в state), `classify_enabled`
(одна точка активации), `journal_layout` (шов раскладки),
`_pool_stale`/`_llm_run_reset`.

## Решения

### 1. Снимок фида — единственная форма фида в state

`FEED_SNAP_KEYS` описывает сериализуемый словарь, `feed_snapshot`
сжимает, `feed_runtime` разворачивает с дописыванием недостающих полей
(старый state не мигрируется на диске — нормализуется на лету).
Новое поле фида = одна правка в `FEED_SNAP_KEYS`, больше нигде.
`article_md` читает поля фида как атрибуты без getattr-костылей.

### 2. Раскладка выделена из _emit_journal

`journal_layout(cfg, opts, articles, jid, imgdir)` — чистая функция
«статьи → секции + первая картинка + failures». `_emit_journal`
отвечает за state, периоды, нумерацию и pandoc. Джанк-гейт и
рубрикация тестируются с одним monkeypatch (`article_md`), без полной
сборки EPUB.

## Отказы (осознанные)

### 3. Фазы run_issue/run_backfill НЕ сводим в общий state machine

Dry-run в `run_issue` переиспользует те же предикаты (`period_ready`),
а не дублирует логику; `finally`-очистка недели в `run_backfill` —
политика «неделя выходит целиком или никак», а не дрейф. Общий
оркестратор добавил бы слой косвенности без снятия реальной боли.
Пересмотреть, если появится третий вид прогона.

### 4. Сеть и извлечение контента НЕ заворачиваем в DI

`http_get`/`fetch_full`/`html_to_md` остаются module-level
функциями, тесты — на monkeypatch (11 целей, топ: http_get ×19).
Для однофайлового CLI monkeypatch — принятый шов; сквозной DI раздул
бы сигнатуры всех внутренних функций ради тестов, не давя ничего
взамен.

### 5. LLM-обвязка НЕ стала run-объектом

Единственный долговременный процесс — webui. Сведение к
`_llm_run_reset()` на старте прогона закрывает баг («жалоба один раз
за жизнь процесса»), не таская run-контекст через `article_md`.
Кэш между прогонами — фича (webui не перечитывает диск), его изоляция
в тестах — autouse-фикстурой, а не ручными сбросами.

## Последствия

- Preview (`feedzine classify`) показывает ровно то, что уйдёт в выпуск.
- Новый тест-сценарий раскладки не требует pandoc и сети.
- Правило протухания пула существует в одном месте (`_pool_stale`).
