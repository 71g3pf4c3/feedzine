# Словарь предметной области feedzine

Короткий глоссарий: как мы называем вещи и где они живут в коде
(`bin/feedzine.py`). Обсуждения, коммиты и тесты должны пользоваться
этими терминами. AGENTS.md отвечает на «как устроен код», этот файл —
на «как это называется».

## Данные

- **Журнал (journal)** — группа фидов со своим заголовком, каталогом,
  периодом и счётчиком выпусков; `feed.journal`, default `main`.
  У каждого журнала свой накопитель; `seen` — один на всех.
- **Накопитель (pending)** — статьи, прошедшие фильтры и ждущие границы
  периода; `state.pending[jid]`. Чистится только после успешной сборки.
- **Seen** — общий пул guid'ов, уже выходивших в выпусках или срезанных
  капом; защищает от повторов между регулярными прогонами.
- **Снимок фида (feed snapshot)** — `FEED_SNAP_KEYS` +
  `feed_snapshot()`/`feed_runtime()`. Единственная форма данных фида в
  state (накопитель, пул ретраев): конфиг фида может измениться до
  выпуска, выпуск живёт на снимке, снятом в момент появления статьи.
- **Прогон** — один вызов `run_issue`/`run_backfill`. Граница жизни
  per-run состояния (сброс «одной жалобы» LLM, сохранение кэша).

## Выпуск

- **Раскладка (journal_layout)** — превращение статей накопителя в
  секции `{имя: [markdown]}`: джанк-гейт, рубрикация, деградации.
  Шов между накопителем и EPUB; не знает про state и pandoc.
- **Секция** — заголовок h2 выпуска. По умолчанию секция фида
  (`feed.section`), при рубрикации по содержанию — рубрика.
- **Рубрикация по содержанию (classify)** — раскладка статей по
  центроидам сидов (ngram) или локальной LLM, а не по принадлежности
  фиду. Активация — `classify_enabled(cfg, jid)`: одна точка решения
  для выпуска и превью.
- **Джанк-гейт** — `article_md` возвращает None, если прозы меньше
  `min_article_chars` и нет скачавшихся картинок. Ссылка-огрызок,
  заглушка paywall и пустая сводка в выпуск не попадают.
- **Деградация** — контент пришёл неполным: полный текст не взялся,
  картинки 403. Собирается в `failures`, показывается читателю в
  секции «Что не попало в выпуск» — никогда не прячется.
- **Пул ретраев / докатка** — `retry_fulltext`: полный текст, не
  взявшийся в выпуске, пробуется снова (`_retry_fulltext`), успех
  уезжает в накопитель секцией «Докатнуто · …». Протухание — единое
  правило `_pool_stale` (попытки/возраст).
- **Лежащий фид** — `down_feeds`: фид, который не синкался с такой-то
  даты. Восстановился — запись исчезает.
- **Дубль** — одна новость с нескольких фидов. Сливается по косинусу
  n-грамм (`dedup_threshold`), кросс-языковые — LLM-дедупом.

## Инфраструктура прогона

- **Запасной путь (fallback)** — LLM-обвязка молча деградирует на
  ngram/extractive; сборка не ломается, но жалоба звучит каждый прогон
  (`_llm_fail` + `_llm_run_reset`).
- **Кэш LLM** — `workdir/llm_cache.json`: ключ модель+шаблон+промпт,
  живёт между прогонами (webui) — это фича, не утечка.
